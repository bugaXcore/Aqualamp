M2 · CONTROL TESTS

Channel test bench

Run one channel at a time, or compare all four at equal levels. Each sequence steps 0 → 25 → 50 → 75 → 100 → 0, with a pause between writes.

Isolate a channel

Other channels stay at zero. Watch the lamp after each step.

One-shot channel check

Set one channel and leave it there. This is the encoded level, not a calibrated measure of visible brightness.

Compare combined intensity

All four channels use the same level. This is not a separate master-dimmer command.

Timer

Sends the clock and the sunrise/sunset frame decoded from the official app. Set the sunset later than the phone's current time, then check the official app afterwards.

Codes 0–5 come from the official app's code. The app only accepts a fade when the on-window is longer than code × 60 minutes.

Power and mode

Frames copied from the official app's code, not yet confirmed on the lamp. Power off sends all four channels at zero; power on also overwrites the timer with an always-on window. Send one at a time.

Fan probe

The FC XX frame is only a candidate; the value range and meaning are unknown. Send one value at a time and confirm each write.

No automatic fan sweep is provided.
